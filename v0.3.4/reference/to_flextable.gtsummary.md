# convert gtsummary to flextable

convert gtsummary to flextable

## Usage

``` r
# S3 method for class 'gtsummary'
to_flextable(x, table_format = autoslider_format, ...)
```

## Arguments

- x:

  gtsummary object

- table_format:

  Function applied to the flextable for styling

- ...:

  additional arguments, not used

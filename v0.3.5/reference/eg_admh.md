# Cached ADMH

Synthetic Medical History Analysis Dataset generated from
[`eg_adsl`](https://pharmaverse.github.io/autoslider.core/reference/eg_adsl.md)
with
[`random.cdisc.data::radmh()`](https://insightsengineering.github.io/random.cdisc.data/main/reference/radmh.html)
version 0.3.16 and seed 130. It contains one or more medical-history
records for 356 of the 400 example subjects. Subjects without medical
history remain in ADSL for population denominators.

## Usage

``` r
data(eg_admh)
```

## Format

A data frame with 1,919 rows and 68 columns, generated by
`data-raw/eg_admh.R`.

## Source

Synthetic data generated by the public
[random.cdisc.data](https://insightsengineering.github.io/random.cdisc.data/)
package; see `data-raw/eg_admh.R` for the reproducible recipe.

## Details

Important columns include subject and study identifiers (`USUBJID`,
`STUDYID`), treatment (`TRT01A`), body system and decoded term
(`MHBODSYS`, `MHDECOD`), sequence (`MHSEQ`), and analysis start
date/time (`ASTDTM`).
